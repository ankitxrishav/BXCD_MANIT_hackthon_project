# **App Name**: Mindwell: Your AI Mood Companion

## Core Features:

- AI Chat Interface: Provides an interface for users to chat with an AI assistant about their mood and feelings.
- Mood Tracking: Tracks user moods and emotions through chat interactions and presents them visually using a mood chart.
- Sentiment Analysis: Analyzes user's chat inputs using AI to detect and classify their sentiments and emotions. Relies on sentiment analysis summaries.
- Voice-to-Text Transcription: Converts voice recordings to text using the Genkit AI flow, allowing users to input via voice.
- Personalized Recommendations: Provides tailored recommendations based on user's emotion and conversation using a Genkit flow. It's powered by the personalized-recommendations tool, which will recommend an item when triggered by certain keywords or detected negative emotions.
- User Authentication: Secures the application, managing user accounts via Firebase Authentication, including Google Sign-In.
- Data Storage & Management: Manages user profiles, chat logs, and preferences in Firestore, applying security rules for data ownership.

## Style Guidelines:

- Primary color: Dark brown (#594D43) to convey stability and trustworthiness.
- Background color: Light beige/off-white (#FAF6F3) for a calm and comfortable feel.
- Accent color: Soft olive green (#A2B59F) to provide a sense of calm and well-being; used for interactive elements.
- Body and headline font: 'Inter' sans-serif for a clean and modern readability.
- lucide-react icons for a consistent and modern look across the UI.
- AppShell: Use a clear app layout, with a header for navigation, dashboard sections for quick access, and a chat bubble for quick access to the AI assistant.
- Subtle transitions and animations for a smooth user experience.
